# Self-contained examples and external references

This distribution keeps the Python/R instructions and inline examples in
[api.md](api.md), [common-patterns.md](common-patterns.md),
[tutorials.md](tutorials.md), [chart-types.md](chart-types.md), and
[r-workflow.md](r-workflow.md). Use them only after selecting the backend.
Their illustrative values are examples, never substitute research results.

For a figures4papers-inspired request, the external source is
[ChenLiu-1996/figures4papers](https://github.com/ChenLiu-1996/figures4papers).
Inspect the requested published reference and its source/permission information
before reusing any material. This package does not include those third-party
images, generated galleries, manuscript-specific demo datasets, or scripts.
Adapt the design relationship using the user's own data and a self-contained
script; do not look for a local `assets/figures4papers` installation.

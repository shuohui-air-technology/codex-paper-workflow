# 先参考后绘制科研配图

用实际查看过的论文配图，指导布局和局部处理；从用户真实材料绘制，再以实际导出与参考对照。

## 范围与保留项

- 适用于统计图、地图、方法流程、模型示意及复合图的新作或实质重设计。用户只要求规划时止于方案；已授权绘制时，继续完成初版、对照和修改。
- 沿用用户已认可的设计、工具、资产和输出要求，不为执行参考流程另起工具链。仅标签、间距或指定接点的小修直接局部修改并核验，不启动完整检索、重设计流程。
- 保护已批准版本，在候选文件中工作。面板、数据、误差定义、模型结构和科学主张来自用户材料，不能从参考补造；不为填满画面加入装饰或无关图元。
- 先查已有参考：出处已确认、实际看图且仍适用的参考可直接复用，包括用户提供的参考，无需补建旧检索日志。缺少可比参考，或图型、布局、风格的改变使旧参考不再适用时，绘制前完成网络检索并实际看图。用户要求离线、禁止搜索或指定唯一参考时遵从；访问受限时继续可独立开展的材料核查和方案，说明未完成的看图步骤。

## 工作流程

### 工作流中的限定任务

独立使用时按下面的完整流程推进。在已启用的自定义工作流中，遵循领取
凭据所限定的阶段：参考设计节点只交付设计与来源记录；视觉复核节点只
查看传入的实际导出、核对设计关系并记录发现。绘图节点由已固定的
`nature-figure` 或现有工具承担；不要在一个领取内另选 Skill。
复核发现需要重画时，交回编排器显式重开绘图阶段，保留已批准版本。
人工确认与 AI 复核分别记录，不能用自己的观察代替人工答复。
工作流接续细节见 [workflow-handoff.md](references/workflow-handoff.md)。

### 1. 确认图要回答的问题

读数据、稿件与现有图，用一句话确定科学目的，确认必要面板、变量、单位及不确定性含义。确定最终尺寸或使用场景、编辑性与交付格式；尺寸未知时用工作尺寸，保留最终尺寸核验待定。

### 2. 搜索并实际查看参考

先查现有记录，已有适用参考无需每轮重搜；需补充时按 [检索与选择](references/search-and-selection.md) 寻找表现任务相近的已发表图，优先原始 figure 页面、全文 PDF 或作者公开全文。查看完整图、图注及决定设计的关键局部；摘要、图注和缩略图不能代替视觉核验。

优先检查用户给定的参考；补充搜索只解决尚未覆盖的表达问题，不因新参考推翻已认可的方向。向用户简短展示最相关的来源与采用理由，只有实际看过时才称“已对照”。

### 3. 提取可执行关系

把参考中的有效做法转成“参考关系 → 本图动作”，例如共用绘图区边缘、标签相对对象的锚点、主次线宽或误差棒构造。复合图的统计、地图和示意面板可各选适用参考，通过共同排版和同角色的颜色、符号、文字规则统合，不强制同一种图元模板；参考冲突时依据科学目的与既定设计选择。

按需读 [局部关系与完成判断](references/micro-style.md) 的相关图型，落实锚点、间距与样式。看不清的细节不能冒充观察结果；将本图适配与参考事实区分。

只在一份现有工作笔记中保留来源链接、图号/页码、实际查看位置、关键取舍和未解决问题；不要求逐项登记或另交完整审计报告。复用他人的素材时，另核查具体许可与署名条件；观察参考不等于取得素材使用授权。

### 4. 绘制并检查导出

数据图从真实源数据重绘，示意图的节点、线条与标签尽量保留原生可编辑。沿用合适的绘图、GIS 或矢量工具。

Python/R 数据图需要补充统计说明、可编辑导出或投稿检查时，按 [与 nature-figure 衔接](references/nature-handoff.md) 调用其适用的实现与 QA。本 skill 负责参考、设计迁移与视觉对照；复用同一份材料和记录，不重复完整流程。GIS、draw.io 及原生矢量示意沿用现有制作方式。

先排布局、标签和连接，再修局部。同类对象共用构造，允许为科学含义、字形或视觉重心作局部适配。不得用随机抖动、故意错位、模糊、低清边缘或任意弯折模拟制作者身份。来源笔记和制作过程留在工作文件，图中仅放有助于理解的内容。

按 [对照与修改](references/comparison-and-review.md) 查看实际导出：整图按相近显示宽度比较；局部选同类对象按相近字高、图元大小或绘图区宽度比较；最终使用尺寸检查可读性。把差距写成具体对象与动作，修正后重新导出；涉及布局时复查整图。无需为普通评审自动创建子代理。

### 5. 交付

交付任务需要的源文件、成图及图注。确认科学内容与编码正确，参考中的适用关系已落实，关键局部及已确定的使用尺寸已检查，实际导出无影响理解的遮挡、缺字或错误符号。最终尺寸未定时可交付工作尺寸候选，明确最终尺寸核验待定，不称最终定稿。报告具体未解决问题；不以“顶刊水平”替代检查结果。用户已认可当前效果后，结束额外风格迭代。

## 查依据或维护规则时

需要解释一条规则的来源、核对投稿规范，或更新本 skill 时，读 [来源与适用边界](references/sources.md)。区分作者建议、感知理论、实验结果、期刊要求与本图判断；新增通用规则前查证原始来源。普通绘图中的参数适配无需逐次做文献检索，具体期刊硬性要求则核对当前官方指南。

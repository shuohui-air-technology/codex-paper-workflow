# 检索与选择

目标是找到能解决当前表达问题的参考，不按篇数完成任务。

## 查什么

从科学目的提取研究对象、图型和视觉问题，例如“多物种年度比较＋重复面板”“模型输入输出＋反馈通道”。先查相近领域，必要时扩大到其他领域的同类图。领域不同的图可以指导排版，不能改变科学叙事。

优先出版者 figure 页面、期刊全文、作者公开 PDF 和可信开放仓储。图片搜索可发现候选，再追到原文和图注。已有参考覆盖需要时停止扩展；缺少某种结构或局部处理时，针对缺口调整查询。

## 看到什么才可用

- 打开 figure 图像或渲染 PDF 相关页，查看完整图，再放大影响本次设计的局部；读图注确认颜色、大小、箭头和误差的含义。
- 只有文字、缩略图或摘要时，标为待视觉核验，不声称已经对照。
- 低清图可指导看得清的布局；不能据此识别准确字体、线宽，或把压缩噪声当作绘制细节。访问受限时说明具体缺口。

## 选哪些

优先选比较关系、文字密度和使用尺寸相近，能表达本图数据与不确定性，并与既定风格兼容的图。参考的局部有缺陷时只借鉴其有效部分；发表期刊的声望不证明适用性。

在现有工作笔记中简短保留原文链接、图号或页码、已查看的图像/页位置、采用的关系及重要限制。无需另建检索日志、逐图评分表或固定文件名。

## 素材实际复用

将他人的图标或插画嵌入本图前，确认单个素材的原始来源、作者、具体许可/授权页面、署名和修改条件。许可不清时自行绘制或换用可确认的素材；不能从论文截图裁图并假定开放使用，也不能用平台首页的泛化描述代替许可。

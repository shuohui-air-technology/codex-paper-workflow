# 与 nature-figure 衔接

本 skill 负责选参考、提取关系和对照修订；`nature-figure` 补充适用的 Python/R 绘图实现、统计说明及投稿输出检查。仅规划时停在方案，不提前触发绘图后端门槛。该 skill 不可用或任务不适用时，继续本 skill 与已有工具流程，不为建立衔接改换工具。

## 选择调用范围

- **Python/R 数据图**：已有明确代码或工作流时沿用对应后端；实际生成前仍未确定且用户未授权推荐时，依 `nature-figure` 的后端规则询问 Python 或 R。选定后，该轨道的绘制、预览、导出及 QA 渲染使用同一后端；依赖缺失时报告具体缺口，不换语言制作替代图。
- **GIS 或原生矢量主导的图**：沿用现有编辑流程，只借用适用的尺寸、字体、源数据或统计检查。不要为调用 `nature-figure` 把地图或可编辑模型改写成 Python/R。
- **混合复合图**：可将明确命名的统计面板作为 `nature-figure` 的独立交付范围，其他面板与整图装配仍由现有流程承担。后端独占检查限定在交给它的面板；不能声称混合工具制作的整图通过了其全图后端独占检查。若任务要求整图走该轨道，先明确装配归属并遵循已选后端。

## 复用现有设计与记录

调用时从现有笔记传入科学目的与主张边界、面板及源数据对应、已看过的参考与关键关系、已确定的布局/配色/样式、尺寸与格式、后端和制作范围。直接复用已经明确的字段，只补本图缺少且适用的信息，不另建第二份 figure contract。

- 优先读取 `nature-figure` 的适用后端指南及 `references/qa-contract.md`；字段不全时按需参考 `references/figure-contract.md`。已有设计足够时，无需再加载整套模板、图例库或风格理论。
- 补齐适用的样本量及重复定义、误差/区间含义、检验信息或模型划分/种子/指标定义，并保持源数据可追溯。材料未提供的检验、对照或统计量标为缺口，不自行新增。
- 保留科学编码和用户已认可的设计。当前期刊明文要求约束投稿输出，冲突时指出具体差异并作必要适配；通用配色、主面板比例、坐标样式和示例字号只用于未定项，不当作期刊硬要求。重复物种、月份或条件面板有比较作用时保留，不为模板层级删减。

## 合并核验与交付

同一次实际导出，同时检查参考中的局部关系、最终尺寸、编辑性、字体/符号、科学编码和统计口径；检查内容仍按图型适配。SVG/PDF 等扩展名本身不证明文字可编辑，紧边界导出后核对实际物理尺寸。

发现问题后按本 skill 的 [对照与修改](comparison-and-review.md) 修正，不另跑一套重复评分或 QA 报告。格式与附带材料按用户和目标期刊需要交付，不默认增加全格式文件包；尺寸或必需统计信息未核实，就准确说明候选状态与缺口。

# 局部关系与完成判断

先看共用关系，再只读当前图型、内嵌图或导出的适用部分。没有的图元不用检查或补造。以下动作是针对当前图的适配方法，不是统一审美标准；需要解释依据时查 [来源与适用边界](sources.md)。

从参考提取相对关系，例如标签间隙相对字高、箭头头部相对线宽、端帽相对点径。看不清时保留近似关系，不声称识别准确字体或尺寸。把同角色的字体、点线、箭头和间距集中到共用样式，先修共同构造，再处理有理由的例外。

## 共用关系

| 对象关系 | 修改动作 | 完成判断与例外 |
|---|---|---|
| 隐含对齐骨架 | 共用实际绘图区边缘、标签基线、模块中心线与主通道锚点；辅助引导线留在工作层 | 重复面板和同角色文字有稳定锚点；不靠含空白的图片外框凑齐。内容需要不同面积时保留差异 |
| 留白与分组 | 分别设置组内间距、组间隔和外边距；移对象或断行，把碎小空隙整理为可识别的分组间隔，再判断是否需框线 | 沿阅读路径能辨认所属组，无夹缝、擦边或靠近错误对象的标签；不规定统一间距倍数，也不为填白增加内容 |
| 标签与对象 | 同类标签设默认相对位置及避碰顺序；无法明确对应时加引线。示意图成列标注可共用基线，引线过长时沿轮廓安排 | 从标签能唯一找到对象。数据点标签相对各点避碰，不全局排成一列，也不移动真实数据；术语、变量与下标、数值与单位不随意拆行 |
| 线与箭头端点 | 先确定含义，再绑定对象边界、端口或通道；按参考选择接触或留间隙。以可见箭尖和描边检查，不能只看路径坐标 | 起止点可追踪，箭尖不埋进文字或边框，间隙不造成目标歧义。同类接点一致，异类按含义区分；连续状态线可接入端口 |
| 路径与连接 | 给主流程、反馈和说明引线分配样式与通道；先留路径空间再布线，区分真实分支点和无连接交叉 | 无意外近切、双重描边或假连接；绕路不误导箭头方向。不为统一角度改变关系，不把所有线改成箭头 |
| 重复图元的比例与透视 | 从母形复制节点、模块或层片，共用投影方向、深度偏移、层间距和锚点；网格从同一组边或变换生成，省略号放在被省略的序列上 | 对应边平行，同角色比例稳定。保留真实大小编码、结构差异或不同视角；不独立旋转每层以制造所谓自然感 |
| 字体与数学排版 | 为面板字母、标题、轴、对象标签和辅助量设角色样式；先调整空间或断行，避免压扁字体。核对字形基线及完整上下标包围范围，再作小幅光学校正 | 同角色文字稳定，普通文本与公式视觉大小和字重可共同阅读；帽号、下标不碰框或邻字。变量、单位和下标按领域/期刊区分；负号、乘号、希腊字母及精度保持正确 |

## 统计图：点、线与误差

| 对象关系 | 修改动作 | 完成判断与例外 |
|---|---|---|
| 比较面板 | 同类型、同尺度比较共用绘图区、刻度逻辑和样式；必要的范围差异明确标识。减弱抢过数据的网格、参考线或边框 | 比较不被轴范围或辅助元素误导；范围调整服务科学目的，不为模仿参考扭曲表达或删观测 |
| 标记及图例 | 分别查看稀疏与密集区域，调整填充、轮廓、透明度和绘制顺序；类别形状按视觉大小协调，图例使用同一构造 | 重叠处类别仍可辨。若大小编码数值，保留真实映射，不作破坏编码的光学校正 |
| 点与误差棒 | 点放在估计值，区间上下端用真实界限；分类偏移后共用同一位置。端帽长度按参考与密度调整 | 区间不被强迫对称，端帽不指向邻组；不加长端帽暗示更大区间。无端帽表达不必补端帽 |
| 被点遮住的短区间 | 先改标记尺寸、描边或绘制顺序；仍不可辨时说明限制或另报数值 | 不放大误差或更换不确定性定义来改善外观 |

实现时按参考与最终尺寸确认参数，默认值合适即可保留；参数含义不明时查当前工具对应属性；[来源页](sources.md#符号与实现机制) 列出误差棒机制的核查入口。

## 地图：地理锚点与周边元素

| 对象关系 | 修改动作 | 完成判断与例外 |
|---|---|---|
| 地理位置与地图框 | 从真实坐标绘制，确认投影和范围适合目的；比较允许时共用地图框、范围与符号，沿地图框或经纬网排刻度 | 无单独拉伸的地理图像；必要的范围或投影差异有标识 |
| 地名、站点与底图 | 标注锚定真实对象，先移文字避碰，必要时加引线；调整海岸线、边界、经纬网权重及图层顺序 | 不移动采样点；底图不抢过研究数据，裁剪和图层不无意遮掉有效观测 |
| 图例、色标及定位图 | 与地图框设稳定边距，符号和颜色沿用真实映射；定位范围框对应主图范围 | 图例可对应数据，定位范围准确；比例尺、指北针按需添加，一旦使用须与本图尺度、方向相符，不能照搬参考 |

## 方法流程与模型示意：结构与阅读路径

| 对象关系 | 修改动作 | 完成判断与例外 |
|---|---|---|
| 真实连接与视觉路径 | 沿输入→处理→输出核对，再布局；反馈、自环、门控和分支从材料取证，结构未知时标为待核 | 线与符号不制造未知结构，关键连接可追踪 |
| 重复阶段及层片 | 共用构造，只改变步骤真实变化的部分；检查数量、颜色和厚度是否暗示量化关系 | 非量化图元不让读者误认比例编码；透视不遮端口或标签 |
| 插画及通道空间 | 沿用认可的轮廓和简化程度；标签或通道不足时先调模块位置与面积 | 风格可共同阅读，不自动混搭线性图标、剪影与彩色插画；不靠极小字号或大量折线塞入内容 |

## 内嵌图与主体

先确认小图是核心证据、局部放大、定位图还是概念示意。核心证据保留可读坐标和必要统计信息；指示图可降低视觉权重，但不能声称它能独立支持结果。

| 对象关系 | 修改动作 | 完成判断 |
|---|---|---|
| 小图样式与宿主 | 共用字体角色、颜色语义、点线构造；先确定小图尺寸，再设字号与线宽 | 不是整张现成图机械缩小；必要标签和编码仍可辨 |
| 锚点、背景与边距 | 小图相对宿主设明确锚点和内边距；检查背景与主体的边界是否需要区分，再决定加框或底色；统计量放在真实空白处 | 无贴边、遮数据或过强边框；视觉上能识别归属，不误认成主体数据 |
| 放大范围及连接 | 核对放大框、连接线和小图范围，检查跨面板裁剪、端点与图层 | 范围对应正确；核心证据仍读不清时扩大或移作独立面板，不靠反复加粗边框补救 |

## 最终尺寸与实际导出

| 检查对象 | 动作 | 完成判断 |
|---|---|---|
| 物理尺寸与缩放 | 核对交付文件物理宽度和目标排版。等比缩放且属性随图缩放时，字、线和标记约乘以“最终宽度/工作宽度”；再检查实际结果 | 非缩放描边、重新排版或紧边界导出未造成意外比例或边距；屏幕 100% 不能代替物理尺寸，尺寸未定时不称完成核验 |
| 真实交付格式 | 有矢量交付时同时查看矢量文件与栅格预览。放大查字体替换、缺字、上下标/帽号、虚线、描边/箭头缩放、裁剪及透明接缝；按最终使用尺寸看类别、端点和标签 | 实际文件可读，无导出新增缺陷；查看器与预览不一致时定位原因，不凭一次异常改坏源图 |
| 栅格资产 | 用原始像素数÷放置尺寸（英寸）检查有效分辨率；查看栅格化后的图例、色标、细线和端帽 | 无关键细节因像素不足或栅格化丢失；提高导出 dpi 不能补回低清资产 |

具体期刊要求从当前官方指南核对，入口见 [来源页](sources.md#期刊指南)。同尺度对照、修改循环及完成判断集中在 [对照与修改](comparison-and-review.md)，无需再生成本文件的逐项审计报告。

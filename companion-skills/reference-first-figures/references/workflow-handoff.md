# 在编排器中交接

从管理器领取的阶段凭据读取项目根目录、选定 Skill、输入列表及结果协议。
同一工作记录以已有内容为输入，各阶段写新的版本，避免改动冻结输入。

参考设计阶段输出科学目的、面板/数据对应、已实际看过的图号与位置、
可执行设计关系、认可的布局配色、尺寸、工具和剩余问题。
新搜到的远程页面用链接、图号和实际观察记录交付；若要读取下载到项目中
的 PDF/图片，先把它作为声明输入登记并重新领取。工具缓存不是科研数据。

视觉复核阶段读取设计、源代码、实际成图和预览，按任务规定检查。
将 AI 发现与用户已经给出的人工确认放在同一记录的不同条目中。
复核新增的重大问题或科学含义问题使阶段保持 blocked，待修订和新版本
人工确认完成再提交通过回执。发现与处置逐项记录；原人工确认只覆盖
其实际检查的版本与内容，不能作为忽略后续发现的依据。
数据图使用编排器提供的 `build_figure_receipt.py` 补齐实际文件哈希并检查
回执；所需科学字段、人工身份和答复须来自真实记录。只提交已声明且
哈希未变的项目来源，按 `node-result-v2` 返回 `consumed_sources`。

该阶段不重画、不更换后端，也不修改运行状态。需要修订时将问题交给
编排器，退回确认并显式重开绘图节点。纯示意或 GIS 图按其原生编辑、
结构/坐标和导出检查验收，不冒充数据图回执。混合图的统计面板回执
仅覆盖命名面板，整图装配单独检查。

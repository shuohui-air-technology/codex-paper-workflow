# 绘图 Skill 分发说明

本项目收录 `reference-first-figures` 和 `nature-figure` 的说明、后端指南、
内嵌示例与工作流适配，按仓库 MIT 许可证分发。两份 Skill 独立安装，
不依赖维护者的本机绝对路径。接入版本保留既定设计优先、同一后端、
统计面板限定范围和共享记录等规则。

分发包只包含工作流所需的文本和内嵌示例。第三方演示代码、论文图像、
图库、个人 R 模板与真实科研数据保留在各自来源，按需单独取得。
引用链接和来源说明仍然保留，用户选用外部材料时按该材料的许可证处理。
指南中的公开来源是参考文献，MIT 分发声明不转授其图片或正文的权限。

先参考后绘图的独立使用路径仍可按需衔接另一份 Skill；在自定义运行中，
两份 Skill 分别绑定到节点，通过冻结输入和管理器回执交接。
新增资源时同步检查文档相对链接、许可、安装回执和真实图件输出。
